# 1. 项目概览

## 1.1 项目是什么

   该项目是一个面向投研人员的 AI 投研工作台，用户登录后可以通过自然语言与 AI 助手“小墨”对话并执行研究任务。平台支持调用专业投研技能、跟踪任务执行进度、管理历史会话，并集中查看生成的研究报告、表格及其他文件。用户还可以将已验证的 对话流程沉淀为可重复使用的私有技能。
## 1.2 解决什么问题

### 原始问题

  传统投研工作通常需要研究人员在多个数据源、分析工具、文档和工作流程之间反复切换。研究任务往往步骤多、执行时间长，过程难以追踪；已经验证过的分析方法也缺少标准化沉淀，导致相似任务需要重复操作。

### 项目解决方案

  项目以 AI 对话作为统一入口，通过技能系统封装不同类型的投研流程。用户既可以直接提问，也可以使用 /技能名 明确启动特定技能，并通过附件补充研究材料；任务执行期间，平台会流式展示回答和进度，并支持权限确认、中止、断线重连及异常情况下的继续或停止决策。

### 最终得到什么

用户最终能够获得一套可追踪、可复用的 AI 投研工作流程，以及由任务生成的研究结论、报告、表格和相关文件。完成一次有效研究后，还可以将流程提炼为私有技能，在后续任务中通过一句话再次调用。

---

## 1.3 项目边界

### 本项目负责

- 提供统一的 AI 投研交互入口，包括自然语言对话、专业技能调用、附件上传和任务中止。
- 管理研究任务的执行过程，包括实时进度、历史会话、断线恢复、权限确认和异常决策。
- 管理和展示投研成果，包括股票池、研究报告、技能目录，以及文件预览与下载。

### 本项目不负责

- 不负责证券交易、自动下单、持仓管理或其他投资账户操作；现有系统定位是研究工作台，不是交易系统。
- 不负责保证外部数据、AI 回答和研究结论绝对准确；最终结论仍需研究人员核验。
- 不负责复杂研究文件的在线编辑或协同办公；文件查看器主要提供预览和下载能力。

> [!warning] 边界
> 本项目用于辅助研究流程和生成投研成果，不应被当作交易执行系统、权威数据源或无需人工复核的投资决策系统。

# 3. 核心概念

> [!note] 使用前建议
> 如果项目存在多个模块、Skill、Agent 或执行阶段，建议先理解下面几个核心概念。

| 概念         | 含义                                 | 使用位置                           |
| ---------- | ---------------------------------- | ------------------------------ |
| AI 问答      | 面向单次问题的轻量入口，可搜索数据、梳理逻辑、撰写内容和生成表格   | 首页 /、问答页 /ask<br>              |
| AI Work    | 面向复杂研究任务的完整工作台，适合多轮分析、研报生成和查看过程产物  | /aiwork、/projects/*<br>        |
| Skill      | 封装特定研究方法、提示词和执行流程的能力包，例如公司基本面研究    | 首页技能卡、/aiwork?view=skills      |
| 会话 Session | 一次连续研究过程的上下文容器，保存问题、回答、附件和执行记录     | URL 中的 sessionId、最近提问、历史记录<br> |
| Agent 执行   | 后端根据问题、Skill 和文件调用模型及工具完成任务的过程     | AI 问答、AI Work 和任务进度区域          |
| 工作区        | 保存可被 AI 引用的资料及生成成果，支持文件夹和历史文件复用    | AI 云盘 /drive                   |
| 附件         | 本次提问临时提交的 PDF、Excel、图片等材料，作为当前任务输入 | 问答输入框、AI Work<br>              |
| 证据与溯源      | 回答中使用的数据、研报原文或会议内容来源，用于验证结论        | 研报、回答引用、会议纪要<br>               |
| 功能模块       | 针对独立业务场景设计的页面能力，不等同于 Skill         | 会议、翻译、云盘、数据面板<br>              |
| 数据面板       | 汇总估值、市场情绪、资金等结构化投研指标               |  /dashboard<br>                |

## 3.1 易混淆概念辨析

| 概念组合 | 定义与核心区别 | 应用场景建议 |
| :--- | :--- | :--- |
| **模块 vs. Skill** | • **模块**：系统的独立功能页面与大类入口<br>• **Skill**：在问答或工作台中调用的具体投研方法论/工具 | 浏览特定功能时进入**模块**；在具体分析任务中选择并调用 **Skill** |
| **会话 vs. 工作区** | • **会话 (Session)**：保存当前的单次交互上下文与对话历史<br>• **工作区 (Workspace)**：长期存储、沉淀文件资产与研究成果 | 临时研讨使用**会话**；重要资料管理与跨任务协作使用**工作区** |
| **附件 vs. 工作区文件** | • **附件**：临时上传，仅服务于当前单次任务/会话<br>• **工作区文件**：持久化存储，可被后续多个任务跨会话重复调用 | 临时补充参考资料用**附件**；核心底层数据、公司研报库用**工作区文件** |
| **AI 问答 vs. AI Work** | • **AI 问答**：轻量级快速对话与即时交互<br>• **AI Work**：工作台模式，适合深度研究与多产出协同管理 | 快速获取信息/简单演算选 **AI 问答**；复杂课题深度研讨选 **AI Work** |
| **回答 vs. 证据** | • **回答**：AI 综合多源信息生成的分析结论<br>• **证据**：支撑结论的原始文件段落、数据表等底层素材 | 日常参考看**回答**；作重大投资决策与合规审查时必须交叉核对**证据** |

  * 检查引用溯源与原始证据
* **步骤 8：成果沉淀**

## 4.1 AI Work

### 模块用途

AI Work 是核心研究工作台，适用于需要深度多轮交互、调用复合技能、生成结构化报告及管理过程文件的复杂投研任务。

### 页面组成

| 区域 | 核心作用 |
| :--- | :--- |
| **左侧工作区** | 管理对话历史、研究报告成果及个人/机构股票池 |
| **中间展示区** | 集中展示生成的报告、数据表格、文件及流程执行结果 |
| **右侧对话区** | 输入研究需求、补充限制条件、唤醒技能及查看推理过程 |

### 主要功能

* **对话与问答**：支持直接向 AI 提问、新建/关闭对话及快速检索重载历史对话。
* **文件与关联**：支持上传本地附件，并结合工作区文件进行深度关联分析。
* **技能调用与提炼**：支持通过输入 `/` 检索技能、根据推荐卡片直接唤醒技能，或将满意的对话流程一键沉淀为个人技能。
* **成果与股票池管理**：在中间展示区预览报告与数据表格，同时支持新建与管理专属股票池。

### 基本使用

* **通用流程**：新建对话 ➔ 描述研究目标 ➔ 上传资料或选择技能 ➔ 等待系统处理 ➔ 右侧对话区查看结论 ➔ 中间展示区查看完整报告或表格

## 4.2 AI 翻译

### 模块用途
AI 翻译是专为投研场景打造的高精度的多语言多格式翻译工具，适用于跨国企业财报、海外行业研报、外文公告及技术图表等资料的即时翻译与语境对齐。

### 页面组成

| 区域 | 核心作用 |
| :--- | :--- |
| **左侧历史与收藏区** | 管理历史翻译记录、收藏的关键翻译成果，并支持快捷新建翻译任务 |
| **中央翻译工作台** | 切换语言对、选择输入类型（文本/文档/图片），以及进行文本输入与翻译触发 |
| **主展示与导出区** | 实时展示双语对照翻译结果，支持原文与译文流转、编辑及成果下载 |

### 主要功能
* **多模态翻译**：支持纯文本粘贴、多格式文档（PDF/Word/Excel）上传及图片 OCR 识别翻译。
* **智能语言识别**：支持自动检测源语言，并快速切换至英语、日语等多国语言互译。
* **历史与收藏管理**：自动归档历史翻译任务，支持对重要翻译结果进行一键收藏与快速检索。
* **快捷方式交互**：支持使用快捷键（如 `Ctrl + Enter`）极速触发翻译，并提供侧边栏灵活收起/展开功能。

### 基本使用
* **通用流程**：选择翻译模式（文本/文档/图片） ➔ 设置源语言与目标语言 ➔ 输入文本或上传文件 ➔ 点击“开始翻译”或使用快捷键 ➔ 在右侧/中央区域查看对照译文并进行收藏或导出

**【示例】**
> “将特斯拉（Tesla）最新发布的 10-Q 财报中关于‘Risk Factors’的段落翻译为中文，保持金融专业术语准确。”

## 4.3 数据面板

### 模块用途
数据面板是整合一级市场/二级市场预测、估值、情绪与资金面数据的实时监控看板。通过聚合 Polymarket、Nasdaq Private Market 等多源数据，帮助研究员直观捕捉市场隐含预期、宏观概率分布及估值演变趋势。

### 页面组成

| 区域 | 核心作用 |
| :--- | :--- |
| **顶部分类导航** | 切换不同类型的数据看板（预测、估值、情绪、资金），并显示各分类下的指标数量数量标记 |
| **隐含估值历史区** | 展示目标公司（如 Anthropic）在一级/私有市场的历史隐含估值走势折线图 |
| **年末估值概率区** | 展示基于预测市场（Polymarket）数据计算的目标公司在年末达到不同估值门槛的概率分布 |
| **宏观概率区（Fed 决策）** | 展示基于宏观市场数据的美联储（Fed）会议利率决策概率分布及历史变化趋势 |

### 主要功能
* **多维数据切换**：支持在“预测”、“估值”、“情绪”、“资金”等多个专业数据维度之间一键切换。
* **隐含估值追溯**：基于 Nasdaq Private Market 等私有市场交易数据，实时展示未上市公司（独角兽）的隐含估值演变轨迹。
* **预测概率可视化**：整合 Polymarket 等预测市场概率，采用“当前曲线”与“历史变化”双维度切片分析年末估值节点概率。
* **宏观利率决策监控**：提供 Fed 会议决策概率预测，支持选择不同美联储议息会议日期查看市场降息/加息预期分布。

### 基本使用
* **通用流程**：选择数据分类（如预测/估值） ➔ 浏览可视化图表 ➔ 切换观察视角（如当前曲线/历史变化） ➔ 调节时间范围或下拉筛选框 ➔ 查看具体概率节点或估值曲线变化

**【示例】**
> “查看 Anthropic 在 Polymarket 上的 2026 年末估值概率分布，重点关注市场预期其估值突破 $1T 以上的具体概率占比。”

### 数据看板与参数调优示例

| 看板维度 | 核心关注点 / 评估维度 | 示例分析场景 (Prompt / 视角) |
| :--- | :--- | :--- |
| **未上市公司隐含估值** | 私有市场交易活跃度、估值折溢价率 | 分析 Anthropic 隐含估值历史曲线，对比 Nasdaq Private Market 交易价格与最新一轮已披露融资估值的偏差。 |
| **年末估值门槛预测** | 概率分布峰值、极端估值概率尾部 | 观察 Anthropic 2026 年末估值概率曲线，评估市场对于 $1T–$1.25T 门槛共识度的集中区间。 |
| **美联储利率决策 (Fed)** | 降息/加息概率、宏观流动性转向 | 选择 2026-09-16 议息会议日期，分析市场对降息 25bps 与 50bps+ 的概率分布比重。 |
| **情绪与资金流向** | 机构持仓变动、市场恐慌/贪婪指数 | 切换至“情绪”与“资金”看板，评估高频资金在科技股与 AI 概念板块的净流入趋势及避险情绪。 |

## 4.4 AI 云盘

### 模块用途
AI 云盘是系统的文件与研究资产管理中心，负责统一存储、归档与沉淀用户主动上传的文件以及各类 AI 任务（如 AI 会议、AI 翻译、技能报告、聊天附件）自动生成的产物，实现研究资料的跨会话长期调用与资产化管理。

### 页面组成

| 区域 | 核心作用 |
| :--- | :--- |
| **左侧导航与目录区** | 提供文件上传入口，管理快捷视图（最近/收藏/回收站）、云盘系统文件夹目录及存储空间占用提示 |
| **右侧主文件列表区** | 展示当前选中目录下的文件列表（支持按名称、来源、大小、时间排序）及全文搜索 |

### 主要功能
* **文件上传与自动归档**：支持主动上传本地资料，同时将 AI 会议、AI 翻译、技能报告与聊天附件自动归类沉淀至系统对应文件夹。
* **目录与快捷视图管理**：预置根目录及 AI 功能分类文件夹，支持快捷查看“最近”使用文件、“收藏”重要文件及“回收站”清理。
* **检索与多维排序**：支持通过文件名进行搜索，并可按“最新优先”等多维度对文件列表进行排序。
* **容量与状态监控**：实时展示当前云盘已用存储空间与总容量上限（如 5.0 GB），并提示容量计费规则。

### 基本使用
* **通用流程**：选择目标文件夹（或使用全局搜索） ➔ 点击“上传文件”添加本地资料 ➔ 浏览系统自动沉淀的 AI 产物 ➔ 针对文件进行预览、收藏、排序或删除管理

**【示例】**
> “在 AI 云盘中找到上周通过‘技能报告’自动生成的 eVTOL 行业研报，将其标记为收藏并导出。”

### 文件管理与场景调优示例

| **AI 会议产物归档** | 自动化同步、纪要与录音关联 | 查看“AI会议”系统文件夹，验证会议结束后的实时转写文本与标准化会议纪要是否自动沉淀。 |
| **AI 翻译成果复用** | 多语言文档归档、跨任务调用 | 访问“AI翻译”文件夹，调取此前翻译好的外文研报 Word 对照件并无缝关联至 AI Work 会话。 |
